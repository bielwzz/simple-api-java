# 📦 Simple API Java  
Aplicação API - FIAP  

Este projeto é uma **API REST desenvolvida em Java 21**, criada como parte de estudos de **desenvolvimento backend** e **arquitetura de microsserviços**.  
A aplicação utiliza **Docker** para containerização e disponibiliza documentação automática via **OpenAPI/Swagger**.

---

## 🧩 Pré-requisitos  
Antes de executar o projeto, certifique-se de ter instalado:  
- ☕ **Java 21**  
- 🐙 **Git**  
- 🐳 **Docker**  

---

## 🚀 Build e Execução  

Para compilar e executar o projeto em um ambiente containerizado, utilize o comando abaixo:  

```bash
docker compose up --build
